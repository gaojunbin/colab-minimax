1. 快速接入 Claude Code (CLI)

无论您的 Claude Code 运行在您个人电脑（远程接入），还是运行在当前服务器本机，均可通过一行命令完成绑定：

方式 A：在您本地电脑远程接入 (Streamable HTTP)

适合在您自己的 Mac / Windows / Linux 终端中连接本服务器：

claude mcp add --transport http --scope user minimax-h3 \
  "http://127.0.0.1:{{ port }}/mcp" \
  --header "X-API-Key: {{ api_key }}"
方式 B：在当前服务器本机接入 (Stdio 进程模式)

直接调用宿主机零依赖脚本 /root/colab-minimax/mcp_server.py：

claude mcp add --transport stdio --scope user minimax-h3 \
  --env MINIMAX_GATEWAY_URL=http://127.0.0.1:{{ port }} \
  --env MINIMAX_API_KEY={{ api_key }} \
  -- python3 /root/colab-minimax/mcp_server.py
通用 JSON 配置 (HTTP / SSE 远程模式)

适用于 ~/.claude.json、Cursor、Cherry Studio、Dify 等客户端（同时支持 /mcp Streamable HTTP 与 /mcp/sse）：

{
  "mcpServers": {
    "minimax-h3": {
      "type": "http",
      "url": "http://127.0.0.1:{{ port }}/mcp",
      "headers": {
        "X-API-Key": "{{ api_key }}"
      }
    }
  }
}
通用 JSON 配置 (Stdio 本地脚本模式)

适用于本机 Claude Desktop / Antigravity / Cline 等支持 Stdio 的客户端：

{
  "mcpServers": {
    "minimax-h3": {
      "command": "python3",
      "args": ["/root/colab-minimax/mcp_server.py"],
      "env": {
        "MINIMAX_GATEWAY_URL": "http://127.0.0.1:{{ port }}",
        "MINIMAX_API_KEY": "{{ api_key }}"
      }
    }
  }
}

2. MCP 工具列表 (8 个内置 Tools)

接入后，您可以直接用自然语言让大模型执行以下操作：

工具名称 (Tool Name) 主要参数 功能说明
generate_video prompt, width, height, duration, turbo_mode, steps, text_encoder, first_frame_image, last_frame_image, wait 全自动唤醒 Colab GPU 并使用 MiniMax H3 生成音视频同步的 MP4，直接保存在 Google Drive outputs/ 目录。
get_video_task_status task_id 根据任务 ID 查询生成进度、状态及 Google Drive 文件路径 (drive_file_paths)。
list_video_tasks limit (默认 10) 列出最近的视频生成任务记录及状态。
list_generated_outputs limit (默认 20) 列出已保存在 Google Drive 云盘中的所有生成视频清单（含云盘路径、大小、生成时间）。
get_instance_status 无 查询当前 Colab GPU 实例状态、GPU 型号、队列任务数、闲置倒计时、Colab 算力余额及日志。
wake_up_instance gpu ("L4"|"A100"|"T4"), wait 主动申请并预热启动 Colab GPU 实例与 ComfyUI 环境。
stop_instance 无 确保生成结果同步落盘至 Google Drive 后，立即释放 Colab GPU 实例以停止消耗算力。
sync_outputs 无 手动触发远端输出目录与 Google Drive 云盘的同步刷新并更新输出索引。

1. 视频生成接口 (POST /api/v1/video/generate)

外部业务系统调用此接口时无需关心 Colab 实例是否在线。若实例已释放，网关会自动完成「申请 GPU → 免交互挂载云盘 → 秒级软链模型 → 生成音视频 → 存入 Google Drive」全流程。

cURL 调用示例 (文生音视频 T2V) 
curl -X POST "http://127.0.0.1:{{ port }}/api/v1/video/generate" \
  -H "X-API-Key: {{ api_key }}" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "Realistic cinematic sci-fi metropolis at dusk, flying cars, rain reflections, stereo synth music and thunder audio.",
    "width": 864,
    "height": 480,
    "duration": 5.0,
    "turbo_mode": true,
    "steps": 8,
    "text_encoder": "heretic",
    "wait": true
  }'
Python 调用示例 (支持图生视频 I2V / 首尾帧 FL2V) 
import requests

resp = requests.post(
    "http://127.0.0.1:{{ port }}/api/v1/video/generate",
    headers={"X-API-Key": "{{ api_key }}"},
    json={
        "prompt": "Camera orbits smoothly around the subject with ambient sound effects.",
        "width": 864,
        "height": 480,
        "duration": 5.0,
        "turbo_mode": True,
        "text_encoder": "heretic",
        "first_frame_image": "https://example.com/start.png",  # 可选：URL 或 Base64
        "wait": True,
    },
    timeout=1800,
)
print(resp.json())
字段名 类型 默认值 说明
prompt * string 必填 画面描述、镜头运动及伴随立体声（台词/音效/配乐）提示词
width / height int 1344 / 768 视频宽高（自动对齐 32 的倍数，常用 864x480 或 1344x768）
duration float 5.0 视频时长（秒，支持 2.0 ~ 15.0 秒，24fps）
text_encoder string "heretic" "heretic" (Momoking Heretic NVFP4) 或 "official" (官方 AWQ)
turbo_mode / steps bool / int true / 8 启用 Turbo LoRA 加速（支持 8 步或 4 步极速生成）
first_frame_image / last_frame_image string null 可选首帧/尾帧图片（支持图片 HTTP URL 或 Base64 字符串）
wait bool true true 同步等待生成完成返回；false 立即返回 task_id 供轮询

2. 任务查询与实例生命周期管理端点

方法与路径 说明
GET /api/v1/video/tasks/{task_id} 查询指定视频生成任务状态、进度描述及输出文件在 Google Drive 中的路径
GET /api/v1/outputs 获取 Google Drive 云盘中所有已生成的视频/音频文件清单
GET /api/v1/instance/status 查询当前 Colab GPU 实例阶段、进度百分比、算力余额及运行日志
POST /api/v1/instance/start?gpu=L4 主动触发唤醒或创建 Colab GPU 实例
POST /api/v1/instance/stop 刷新同步输出到 Google Drive 并立即释放 Colab GPU 实例
