接入文档

通过 MCP 或 REST API 调用 MiniMax H3。实例休眠时，请求会自动唤醒 GPU。

网关地址 http://127.0.0.1:{{ port }}
API Key {{ api_key }}
Swagger

连接

在任意电脑上通过网络连接网关。

Claude Code 与网关运行在同一台服务器时使用。

Claude Code
claude mcp add --transport http --scope user minimax-h3 \
  "http://127.0.0.1:{{ port }}/mcp" \
  --header "X-API-Key: {{ api_key }}"
Claude Code
claude mcp add --transport stdio --scope user minimax-h3 \
  --env MINIMAX_GATEWAY_URL=http://127.0.0.1:{{ port }} \
  --env MINIMAX_API_KEY={{ api_key }} \
  -- python3 /root/colab-minimax/mcp_server.py
Cursor、Claude Desktop、Cherry Studio 等客户端
{
  "mcpServers": {
    "minimax-h3": {
      "type": "http",
      "url": "http://127.0.0.1:{{ port }}/mcp",
      "headers": {
        "X-API-Key": "{{ api_key }}"
      }
    }
  }
}

仅支持 SSE 的客户端，请使用 http://127.0.0.1:{{ port }}/mcp/sse?api_key={{ api_key }}

Claude Desktop、Antigravity、Cline 等客户端

}

工具

接入后，直接用自然语言让模型调用以下工具。

生成

  • generate_video

    生成音画同步的视频，支持文生视频、图生视频与首尾帧控制；图片可传本地路径、URL 或 Base64。实例休眠时自动唤醒。

    promptwidthheightdurationturbo_modestepstext_encoderfirst_frame_imagelast_frame_imageseedwait

  • get_video_task_status

    查询任务进度、状态与 Google Drive 文件路径。

    task_id

  • list_video_tasks

    列出最近的生成任务。

    limit（默认 10）

  • list_generated_outputs

    列出已保存在 Google Drive 的生成文件，含路径、大小与时间。

    limit（默认 20）

实例

  • get_instance_status

    查询实例状态、GPU、队列、闲置倒计时、算力余额与日志。

  • wake_up_instance

    启动 GPU 实例并部署 ComfyUI。

    gpu（L4 / A100 / T4）wait

  • stop_instance

    将结果同步到 Google Drive 后立即释放实例，停止消耗算力。

  • sync_outputs

    手动将远端输出同步到 Google Drive 并刷新索引。

认证

每个请求都需要携带 API Key：使用请求头 X-API-Key 或 Authorization: Bearer，也可以使用查询参数 api_key。

生成视频

POST/api/v1/video/generate

实例休眠时会自动申请 GPU、部署 ComfyUI 并执行生成，结果保存至 Google Drive。

curl -X POST "http://127.0.0.1:{{ port }}/api/v1/video/generate" \
  -H "X-API-Key: {{ api_key }}" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "Realistic cinematic sci-fi metropolis at dusk, flying cars, rain reflections, stereo synth music and thunder audio.",
    "width": 864,
    "height": 480,
    "duration": 5.0,
    "turbo_mode": true,
    "steps": 8,
    "text_encoder": "heretic",
    "wait": true
  }'
import requests

resp = requests.post(
    "http://127.0.0.1:{{ port }}/api/v1/video/generate",
    headers={"X-API-Key": "{{ api_key }}"},
    json={
        "prompt": "Camera orbits smoothly around the subject with ambient sound effects.",
        "width": 864,
        "height": 480,
        "duration": 5.0,
        "turbo_mode": True,
        "text_encoder": "heretic",
        "first_frame_image": "https://example.com/start.png",  # 可选：URL 或 Base64
        "wait": True,
    },
    timeout=1800,
)
print(resp.json())

请求参数

字段类型默认值说明
prompt*string必填画面、镜头运动与伴随音频（台词、音效、配乐）的描述
width / heightint1344 / 768视频宽高，自动对齐到 32 的倍数；常用 864×480、1344×768
durationfloat5.0时长（秒），2–15 秒，24 fps
text_encoderstring"heretic""heretic"（Heretic NVFP4）或 "official"（官方 AWQ）
turbo_mode / stepsbool / inttrue / 8Turbo LoRA 加速，可设 8 步或 4 步；关闭 Turbo 时默认 20 步
first_frame_image / last_frame_imagestringnull首帧 / 尾帧图片，HTTP URL 或 Base64
seedint随机随机种子
workflowobjectnull自定义 ComfyUI API Prompt，传入后直接执行该工作流
waitbooltruetrue 等待生成完成后返回；false 立即返回 task_id 供轮询

其他接口

  • GET/api/v1/video/tasks/{task_id}查询任务状态、进度与输出文件
  • GET/api/v1/video/tasks最近的任务列表
  • GET/api/v1/outputsGoogle Drive 中的生成文件列表
  • GET/api/v1/outputs/{file_path}下载生成文件（实例运行时可用）
  • GET/api/v1/instance/status实例阶段、进度、算力余额与日志
  • POST/api/v1/instance/start?gpu=L4启动或唤醒 GPU 实例
  • POST/api/v1/instance/stop同步结果到 Google Drive 并释放实例
  • POST/api/v1/instance/sync手动同步输出到 Google Drive

任务状态依次为 pending_instance → uploading_inputs → queued → running，最终为 completed 或 failed。

原生 ComfyUI 接口

任何 ComfyUI 客户端都可以直接连接网关地址（携带 API Key），使用 /prompt、/upload/image、/history、/queue 等原生端点。实例休眠时，请求 /prompt 会自动唤醒实例，就绪后再转发执行。
