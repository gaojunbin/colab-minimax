支持 Claude Code / LLM 与外部系统调用

完整接入文档 ↗
一行命令添加到本地 Claude Code： 
claude mcp add --transport http --scope user minimax-h3 \
  "http://127.0.0.1:{{ port }}/mcp" \
  --header "X-API-Key: {{ api_key }}"
按需自动唤醒并生成音视频： 
curl -X POST "http://127.0.0.1:{{ port }}/api/v1/video/generate" \
  -H "X-API-Key: {{ api_key }}" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"Sci-fi city dusk, flying cars, synth music","width":864,"height":480,"duration":5}'
